# VGZT Season 7 poster provenance

Season 7 archive at <https://sites.google.com/view/gastrulationseminars/past-talks>.

comment. Filenames preserve the verified seminar date and speaker surnames.

Google Sites exposes these historical originals through its rendered asset
URLs at 1280 px wide; those highest publicly retrievable versions are stored
here so production never hotlinks Google.
